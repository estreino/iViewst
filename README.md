# iOS WebKit PWA Immersive HTML Viewer (Final Definitivo)

Aplicativo PWA de tela 100% imersiva ponta a ponta (Edge-to-Edge) para iOS (otimizado para iPhone 15 Pro Max), com Guardião Silencioso, botão mestre totalmente livre até as bordas, menu ancorado na engrenagem, auto-save por projeto, reset de fábrica (long-press 2s na engrenagem), confirmação de exclusão e notificações inteligentes.
